# Contributing to My First Repo

Thanks for your interest in contributing! This guide explains how to work on this project so everyone stays on the same page.

## Ways to contribute

- Report bugs or issues you find
- Suggest new features or improvements
- Submit pull requests with changes you have made

## Getting started

1. Fork the repository or create a feature branch.
2. Keep changes small and focused on one thing at a time.
3. Write clear commit messages that describe what you changed and why.
4. Test your changes before opening a pull request.

## Pull request guidelines

- Open pull requests from a `feature/...` branch, never directly to `main`.
- Give every pull request a descriptive title that starts with a category, for example `Docs:`, `Feat:`, or `Fix:`.
- Describe what you changed in the description and why it matters.
- Link the pull request to any related issue when possible.
- Keep the description short, but make it clear enough that a reviewer can understand the change without asking questions.

## Code of conduct

Be respectful and constructive in all discussions. We want this project to be a welcoming place for everyone.
